# Investigating Netflix's Fitness Trends — Python Data Analysis

## Project Overview
A data analysis project taking the perspective of a product manager 
at a fitness studio, using Google Trends data to understand the demand 
for digital fitness products and identify growth opportunities in the 
global fitness market.

## Business Question
Are fitness studios and digital workout products experiencing genuine 
long-term growth, or is the demand a short-term trend?

## Datasets Used
| File | Description |
|------|-------------|
| `workout.csv` | Global popularity of the keyword 'workout' over time |
| `three_keywords.csv` | Popularity of gym, home workout and yoga keywords |
| `workout_geo.csv` | Geographic distribution of workout interest by country |
| `three_keywords_geo.csv` | Geographic comparison of all three keywords |

## Analysis Performed
- Time series analysis of global fitness keyword trends
- Comparative analysis of gym vs home workout vs yoga demand
- Geographic breakdown identifying highest-interest countries
- Trend identification for digital fitness product opportunities

## Tools & Libraries
- **Python** — core language
- **Pandas** — data loading, cleaning and manipulation
- **Matplotlib** — time series and comparative visualisations
- **Jupyter Notebook** — interactive analysis environment

## Key Skills Demonstrated
- Real-world business problem framing using data
- Time series trend analysis
- Multi-dataset comparative analysis
- Geographic data interpretation
- Translating data insights into business recommendations

## How to Run
1. Clone this repository
2. Ensure all CSV files are in the same directory as the notebook
3. Open `notebook.ipynb` in Jupyter Notebook or JupyterLab
4. Run all cells in order
